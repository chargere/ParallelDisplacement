尖塔着色标签 — 常见错误
================================

相关文件
--------
  src/main/resources/hongwenResources/localization/eng/
    Relicstrings.json / Cardstrings.json / Powerstrings.json

游戏里遗物、卡牌、能力说明会把 `#y` `#b` 当成着色指令吃掉。
吃失败时，玩家会看见字面量 `#y` 或 `#b`。

2026.8.26 在战斗精英起始遗物上踩过：棱镜 `#y倍镜。#y红点` 漏 `#y`；violetaurora `+#b10%` 漏 `#b`。


一、解析规则（按「词」切，不是按字）
--------------------------------
`#y` / `#b` / `#g` 必须出现在**一个词的开头**。词以空格切开。

  正确：  `#y破绽`     `#b2`     `#b+8`     `#b-1`     `#b10%`
  错误：  `+#b10%`     `#b×1.5`   `#y倍镜。#y红点`   `恢复量×#b3`
          `当前层数：#b5`     `#b4/#b5/#b6`     `#b1.5`

`#y` 后面跟已注册关键词（烬火、霜寒、破绽、虚无、消耗…）时，关键词匹配器会单独吞掉那个词，后面紧跟 `。` 往往还能过。
`#y` 后面跟**未注册**的词（红点、倍镜）时，从 `#y` 一直吃到下一个空格。句号、下一个 `#` 都会变成这个词的一部分，于是第二个 `#y` 印到屏幕上。

精绝关键词（沙漏、虚数、眼印、处决、处决线、溅射、时滞、虚化、业火、血印）不要手写 `#y`。
更不要把它们粘在别的汉字中间：`获得沙漏时`、`眼印提高` 会被 ExtendedUI 插成 `获得#y沙漏时`，字面量 `#y` 就会露出来。
卡牌 / 遗物 / 能力在显示前会走 `JingjueDesc.isolate`，把这些词拆成独立词。


二、禁止的写法
--------------
1. 运算符写在 `#b` 前面

     受伤 +#b10%     伤害 +#b2     倍率 ×#b3
     → 改成   增加 #b10%    伤害 #b+2    倍率 × #b3
     完整数字在同一段字符串里：用 `#b+8`，不要用 `+#b8`。
     拼接数值时：前缀写成 `"伤害 #b+"` + amount，不要写成 `"伤害 +#b"` + amount。

2. `#b` 后面直接跟 ×、x、中文，或两个 `#b` 挤在斜杠里

     #b×1.5     恢复量×#b3     #b4/#b5/#b6
     → 改成   恢复量 × #b3     #b4 / #b5 / #b6

3. 两个着色标签黏在标点上（尤其是未注册词）

     #y倍镜。#y红点
     → 改成   #y倍镜 。 #y红点
     每个 `#y词` / `#b数` 前后留空格，再写 `。` `：` `，`。

4. 冒号后直接接 `#b`（拼接层数时最常见）

     当前层数：#b     剩余次数：#b
     → 改成   当前层数： #b     剩余次数： #b
     拼出来必须是 `当前层数： #b5`，让 `#b5` 自己成词。

5. 小数不要着色：`#b1.5` / `#b0.75`

     卡面描述遇到小数点会把 `#b` 漏到屏幕上（红点、倍镜选项卡踩过）。
     → 写成不着色的 `1.5 倍`，或改用整数 `#b150%` 。

6. 不要单独丢一个 `#y` 或 `#b` 在句尾等「下一词」


三、推荐模板
------------
  层数    给予 #b2 层 #y破绽 。
  倍率    左边 1.5 倍，右边 0.75 倍。（小数不要加 #b）
  加算    攻击牌伤害 #b+8 。
  拼接    DESCRIPTIONS[0] = "下一次受到的攻击伤害 #b+"
          代码里再 + amount
  动态层  DESCRIPTIONS[0] = "……当前层数： #b"
          代码里再 + amount


四、实装后怎么查
----------------
在 localization/eng 下搜：

  +#b
  ×#b
  #b×
  ：#b
  /#b
  #b1.
  。#y
  。#b

搜到就按上面改。改完进游戏看遗物/能力浮窗，不要只看 JSON。


五、2026.8.26 扫描结果
----------------------
卡牌（Cardstrings）
  未发现 +#b / ×#b / ：#b / /#b。
  凯文、多米尼克、蛋蛋卡面多用 !D! / !M!，或写成「伤害 +3」不着色，所以不会漏标签。
  棱镜选项卡 PrismRedDot / PrismScope：不要写 `#b1.5`，改成不着色的 `1.5 倍`。
  草稿 tools/fvv_cards_append.json 里有 +#b1，没有进正式 Cardstrings，不要抄回去。

遗物（Relicstrings）
  已修：棱镜光学分析系统、violetaurora。
  `#b+8`（星锻未完成稿）是正确写法，保留。
  `#y烬火。每当` 能过，因为 烬火 是注册关键词。新词不要学这个黏法。

能力（Powerstrings）——本轮一并修
  天火·命定     伤害 +#b2 / +#b1     → #b+2 / #b+1
  红温·极意     恢复量×#b3           → 恢复量 × #b3
  沉默的守望    静默倍率 ×#b         → × #b   （拼接）
  星痕          伤害 +#b             → #b+    （拼接）
  开刃预备      伤害 +#b             → #b+
  开刃宗法      伤害 +#b             → #b+
  顺路一剑      额外 +#b / 再 +#b    → #b+
  精灰          伤害 +#b             → #b+
  破绽          合计 +#b             → #b+
  烬火 / 静电印记 / 烬雷回响 / 霜寒 / 星痕
                当前层数：#b / 剩余次数：#b   → 冒号后加空格
  焚天·永燃     #b4/#b5/#b6          → #b4 / #b5 / #b6
