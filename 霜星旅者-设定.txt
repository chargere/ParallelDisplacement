============================================================
基础信息
============================================================

称号：霜星旅者
化名：多米尼克·梅隆蒂科
属性：星辰 / 冰雪

一句话：
来自星空的旅者，本不打算进入尖塔。但他看见有人在死定了的时候还往前走，就顺手帮他们开了一段路。

============================================================
背景设定
============================================================

多米尼克·梅隆蒂科，来自某颗早已无法在星图上被找到的行星。他的种族不筑城、不立碑、不保存任何超过两代人的记忆。生来便以观测和记录为业，不干预任何文明的进程。他在宇宙中走了很久，久到记不清见过多少种终结的方式。

他降落在这颗星球时，荒疫已经吞没了三分之二的大地。他在飞船里待了三天，看着灰白色的侵蚀线在地图上缓慢推进，然后他走出舱门，踩碎了第一片冰壳。他本打算停留三个月，完成记录就走。三个月后他还在那颗星球上。

尖塔最底下那层，他第一次遇到凯文。那个家伙手里攥着一把磨损严重的折叠刀，脸上全是灰，和身后十几个同样狼狈的兵士挤在篝火边。多米尼克从旁边经过，看了他们一眼——他见过太多这种表情，那种“我知道我活不到明天，但我还是要上”的表情。他本来准备绕过去。凯文抬头，正好看见他衣摆上未化的霜，和他腰间那柄没有任何装饰的长剑。

“你要上去吗？”凯文问。
“可能。”
“那一起走。”
“你们走得太慢了。”
“密码的，那你塔姆走你的。”

凯文低下头，继续擦拭手里那把刀的折叠机关。多米尼克站在原地，看了他一会儿。他不记得自己为什么停下来。可能是因为凯文回答“那你走你的”的时候，语气和他见过的所有将死之人都不一样——没有怨，没有惧，甚至没有请求。也可能是因为，那把名为“怜悯”的刀明明已经很钝了，他还在擦。

他后来跟着凯文走了很长一段路。他的冰拦住凯文来不及挡的灰线，他的星光在夜晚为队伍照出荒疫未覆盖的安全路径。他不承认自己在帮忙，他更愿意称之为“顺路”。但顺路顺了这么久，连他自己都知道那不是实话。他的剑偶尔也会出鞘——在那些凯文挡不住的时候。

有一天晚上，他看着凯文坐在火边仔细擦拭折叠刀的转轴，刃口已经磨得只剩浅浅一层。他忍不住问了一个他很少问的问题：

“你们明明知道赢不了，为什么还要走？”

凯文抬头看他，眼神很平静。

“你怎么知道赢不了？”

多米尼克愣了一下。他见过这么多星球的结局——他确实知道。他见过荒疫三次，三次都没有幸存者。但他没有说出这句话。

凯文继续擦刀，没等他回答。

“我生在这片土地上。荒疫来了，我挡了，我死了——这叫什么赢不了？这就是赢。”

多米尼克很久没说话。他低头看了看自己腰间那柄从不离身的长剑——那是一柄未完成的星锻剑，剑身还留着冷却时的云纹，没有开刃，没有铭文。他从没认真用过它。他后来在星图那页最底边写了一行小字：

“这颗星球上的文明终结方式，我没有见过。他们不祈求，不逃避，不投降。他们只是……往前走。”

他从来没有这么写过。他写过的所有观测记录都像数据，只有这一句，像一个人被另一个人打动了。

荒疫还在蔓延。塔还在上面。凯文的折叠刀还会继续卷口。多米尼克知道结局——他见过太多次荒疫，他知道没有例外。但他的“星图”已经合上很久了。他还在走。

他不能阻止结局。他只是想不起上一次握紧自己的剑是什么时候了。

============================================================
机制草稿（讨论中，未实装）
============================================================

总原则：
- 出伤与防御天花板高于凯文，但必须付代价（「力气大，有代价」）。
- 主代价方向：时序债（B）+ 记录债（C，消耗/放逐等）。
- 不做「烧血」作主代价。

------------------------------------------------------------
【保留】常驻代价词条（类似 消耗 / 虚无）
------------------------------------------------------------

三轴分工 + 状态（当前已留）：
  轮转/手牌 → 迟滞（卡面词条）
  防御       → 冻裂 X（卡面词条）
  攻击       → 星灭（卡面词条）
  记录       → 归墟 X（本回合状态）

----- 迟滞（手牌债）-----

效果（已定）：
  迟滞 —— 打出此牌后，在本回合中，手牌里与其相邻的两张牌各费用 +1。

细则备忘：
  - 「相邻」指打出瞬间、移出手牌之前，左右各一张（若存在）。
  - 若只有一侧有牌，只影响那一侧；若打出时手牌仅此一张，则无额外代价。
  - +1 费仅持续本回合；回合结束清除。

----- 冻裂（防御债）-----

效果（已定）：
  冻裂 X —— 打出此牌后，本回合失去 X 点敏捷。

设计意图：
  - 挂在「单次巨额格挡 / 冻壁」上：这一下可以很厚，但本回合后续格挡效率被敏捷惩罚拖住。
  - X 写在卡面上（冻裂 1 / 冻裂 2…），和力量减益一样好读。

细则备忘：
  - 失去的敏捷为临时（本回合），回合结束恢复；具体用「临时敏捷 -X」或「本回合敏捷 -X」实现即可。
  - 打出前已有的格挡不动；惩罚通过敏捷影响此后的格挡获取。
  - 若本回合敏捷被减到负数，按尖塔常规处理（负敏捷减格挡）。

----- 星灭（攻击债）-----

效果（已定）：
  星灭 —— 打出此牌后，本回合无法再打出攻击牌。

设计意图：
  - 挂在「巨量伤害 / 星刃终结」后面：这一下可以脏过凯文，但回合输出到此为止。
  - 贴「未开刃星锻剑偶尔出鞘」——出鞘就是决断，不是连斩。

细则备忘：
  - 星灭在本张牌结算后生效；本张星灭攻击本身正常打出。
  - 本回合仍可打技能/能力（防、轮转、解债）。
  - 与迟滞可同卡，但慎与过多代价叠满。

----- 归墟 X（本回合状态 / 记录债）-----

形态（已定）：
  不是卡面常驻词条，而是打出某些牌后获得的「本回合状态」（玩家身上的层数 Power）。
  回合结束清除未用完的层数。

效果（已定倾向）：
  归墟 X —— 本回合中，接下来打出的 X 张牌会被消耗；每因此消耗一张，层数 -1。

设计意图：
  - 挂在超模牌后面：这一下很强，但本回合后续打出的牌会被「写进星图外 / 抹掉」。
  - 贴种族「不保存超过两代人的记忆」——用力之后，记录被烧掉。

细则备忘：
  - 默认不消耗「赋予归墟的那张源牌自身」（源牌有没有消耗自己写）；只影响之后打出的牌。
  - 仅本回合有效；跨回合不残留。
  - 与迟滞/冻裂/星灭可同回合并存，但单卡慎把账叠满。

已留一览
------------------------------------------------------------

卡面常驻词条（类似 消耗 / 虚无）：

| 词条 | 轴   | 一句话 |
|------|------|--------|
| 迟滞 | 轮转 | 本回合邻牌各 +1 费 |
| 冻裂 X | 防御 | 本回合失去 X 点敏捷 |
| 星灭 | 攻击 | 本回合不能再打攻击 |

本回合状态（层数，回合末清）：

| 状态 | 轴   | 一句话 |
|------|------|--------|
| 归墟 X | 记录 | 本回合接下来 X 张打出的牌消耗 |

待决（全局）：
  - 是否做「解债」小牌（清迟滞、补敏捷、清归墟；星灭一般不建议轻易解）
  - 归墟是否对能力牌 / 状态牌同样生效（倾向：凡打出的牌都算，能力也耗）

------------------------------------------------------------
【保留】冰雪侧：力气本体（挂自己）
------------------------------------------------------------

与星辰分工（已定方向）：
  - 星辰 = 账单 / 许可（迟滞、冻裂、星灭、归墟）
  - 冰雪 = 数值与节奏（叠势、兑现）；不负责再堆一套负面词条

主资源（已定）：
  蓄寒 —— 挂在玩家自己身上的层数。
  理由：挂敌人会因击杀/换目标白挂；挂自己跨单位、跨小怪都还在。

冰雪牌三类（已定设计思路）：

  1）常态牌（无门槛）
     - 正常打数值（伤 / 盾 / 小效用），效果完整可读。
     - 不依赖蓄寒也能用；是牌组的底板。

  2）阈值强化（够层才强化，并消耗对应层数）
     - 正文写基础效果；额外写：若蓄寒 ≥ X，则强化，并消耗 X 层蓄寒。
     - 强化可以是：加伤、加盾、额外段、抽牌、上星辰许可等。
     - 层数不够：只结算基础效果，不耗层（或写明「不够则不强化」）。

  3）全层引爆（一次吃光）
     - 消耗当前全部蓄寒。
     - 按消耗的层数落入不同效果档位（例：1–2 / 3–5 / 6+，档位数值待定）。
     - 适合终刀、冻壁终极、控场变体；常挂星灭 / 归墟 / 冻裂等星辰账单。

刻意不对位凯文：
  - 不做「敌人印记 + 每击小加伤」
  - 不做传导；群伤靠一次冰爆结算

待决（冰雪）：
  - 资源是否就叫「蓄寒」（若改名「虚寒」再替换）
  - 阈值强化的典型 X（1 / 2 / 3）与强化幅度
  - 全层引爆的档位表（几档、每档给伤/盾/其他）
  - 蓄寒有无软上限；跨回合是否掉层
